# CFINet

This directory contains the CFINet implementation integrated into the Small Object Detection project.

## Paper

**Small Object Detection via Coarse-to-fine Proposal Generation and Imitation Learning**

Published at ICCV 2023.

## Description

CFINet is a small object detection framework based on coarse-to-fine proposal generation and imitation learning.

## Repository Structure

* `CFINet/` - CFINet implementation
* `configs/` - Model configuration files
* `mmdet/` - Modified MMDetection components
* `tools/` - Training and evaluation utilities
* `demo/` - Demo scripts
* `tests/` - Testing files

## Environment

* Python 3.8
* PyTorch 1.10.0
* CUDA 11.3
* MMCV 1.5.0
* MMDetection 2.26.0
* NumPy 1.22.4

## Integration

CFINet is integrated into the Small Object Detection project alongside YOLO-based detection models.
